## Platform
web

## Users
The case's admin and sales-demo users manage product/knowledge records and inspect a shared customer quote. The hiring reviewer evaluates the actual backend behavior.

## Product Purpose
Turkish, source-grounded quote assistance with six real backend tools and shared web/native state.

## Capabilities and Constraints
The approved vault plan requires product/knowledge list and add, canonical quote with discount/history, small streaming chat, and real tool logs. No client pricing or optimistic quantity mutation. PostgreSQL is authoritative. This is a local demo without production authentication; no public deployment is authorized.

## Brand Commitments
The Blue Red name; Turkish plain-language B2B controls. Preserve the existing blue/red, light surface and system typography. The user prioritizes backend correctness over decorative work and authorizes autonomous implementation of the existing plan.

## Evidence on Hand
Live seeded API, 22 HTTP golden scenarios and reports/f01–f05 evidence. Physical iPhone debug stream observed by Mustafa; full native chat has not yet been observed.

## Product Principles
Show recorded values and source provenance. Keep failures visible and recoverable. Preserve message identity on retry. Keep all money calculations on the server.
